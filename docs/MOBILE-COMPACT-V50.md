# MBN Mobile Compact v50

## Mục tiêu

- Mobile gọn hơn desktop một cách có chủ đích.
- Input/select thấp hơn nhưng vẫn giữ cỡ chữ 16px để tránh Safari iOS tự phóng to.
- Nút thấp hơn, padding và khoảng cách nhỏ hơn.
- Bộ lọc giữ hai trường mỗi hàng ở 320–430px.
- Footer thẻ tài khoản luôn giữ giá và nút xem trên cùng một hàng.
- Không thay đổi API, contract, route hoặc nghiệp vụ.

## Kích thước canonical

- Input/select mobile: 36px.
- Button mobile thường: 34px.
- Button nhỏ: 32px.
- Panel padding: 8–10px.
- Gutter: 8–10px.
- Khoảng cách section: 9px.
- Header action: 26px.

## Kiểm tra

```bash
npm run check:mobile-ui
npm run check:mobile-density
```

# Thuật ngữ hiển thị MBN

Giao diện sử dụng tiếng Việt đầy đủ, rõ nghĩa và nhất quán.

| Thuật ngữ cần tránh | Cách dùng thống nhất |
|---|---|
| Checklist | Danh sách kiểm tra |
| Game | Trò chơi |
| Account | Tài khoản |
| Nick | Tài khoản trò chơi; có thể viết “tài khoản” trong nút ngắn |
| Topics | Bài viết hoặc cẩm nang |
| Profile | Hồ sơ cá nhân |
| Marketplace | Khu mua bán |
| Listing | Tin đăng |
| Seller / Buyer | Người bán / Người mua |
| Rental | Thuê |
| Installment | Trả góp |
| Deposit | Đặt cọc hoặc nạp tiền tùy ngữ cảnh |
| Timeline | Tiến trình hoặc diễn biến theo thời gian |
| Reserved | Đã giữ chỗ |
| Loading | Đang tải |
| Refresh | Tải lại |
| Filter | Bộ lọc |
| Reset | Đặt lại |
| Modal | Hộp thoại |
| Slider / Carousel | Trình chiếu ảnh / danh sách trượt |
| Mobile / Desktop | Điện thoại / máy tính |
| Mock data | Dữ liệu mẫu |
| Full-screen loading | Màn hình chờ toàn trang |

Tên riêng và viết tắt như Zalo, Facebook, QR, OTP, API và 2FA được giữ nguyên. Khi xuất hiện lần đầu trong nội dung hướng dẫn, cần có giải thích bằng tiếng Việt.
